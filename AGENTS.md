# Antigravity Agent Rules

## Auto-Deployment
Whenever you successfully finish implementing a set of requested changes or fixes, you must automatically:
1. Commit all your changes to the `main` branch with a descriptive commit message.
2. Push the changes to `origin main` to trigger the deployment.
3. Inform the user that the changes have been deployed. 

Do not wait for the user to explicitly ask you to deploy.
