2.1 Global content rule

One headline per section.

Maximum one short supporting sentence per section header.

Maximum two buttons in any section.

Card descriptions: maximum 14 words on desktop and 10 words on mobile.

No homepage paragraph should exceed 22 words.

Do not repeat the same message in multiple sections.

3. Header and navigation

3.1 Desktop

Keep the logo left aligned and vertically centered.

Use these primary items: Find Professionals, Brands, Schools, Marketplace, Journal, For Business.

Move Jobs and Events into an Explore dropdown if space is tight.

Keep account/search icons together with consistent 40–44px clickable areas.

Use one highlighted gold button: “List your business”.

Header height: 72–80px. Do not allow a second line of navigation.

3.2 Mobile

Show only the logo, search icon and menu button in the closed header.

Header height: 64–72px. Icon touch targets: minimum 44×44px.

Mobile menu order: Find Professionals, List Your Business, Marketplace, Jobs, Schools, Events, Journal, Account.

Make “List Your Business” the only filled button inside the menu.

Lock background scroll while the menu is open and return keyboard focus to the menu button when closed.

3.3 Header acceptance

No clipped text from 320px through 1440px viewport widths.

No horizontal page scrolling.

Sticky header, if retained, must not cover anchored headings.

11.3 Premium-look rules

Use whitespace and strong imagery instead of extra explanatory text.

Limit gold to labels, emphasis and primary actions. Do not turn whole sections gold.

Use one radius system, one shadow system and one button system throughout the homepage.

Avoid heavy gradients, floating glass panels, excessive animation and multiple competing accent colors.

Animations must be subtle, respect prefers-reduced-motion and never delay interaction.

Use WebP/AVIF images with explicit width and height to prevent layout shifts.

12. Responsive, accessibility and performance requirements

12.1 Required test widths

Mobile: 320px, 360px, 390px and 430px.

Tablet: 768px and 1024px.

Desktop: 1280px, 1440px and 1920px.

12.2 Accessibility

Visible keyboard focus on every link, button, menu, carousel control and form field.

Text contrast must meet WCAG AA: 4.5:1 for normal text and 3:1 for large text.

Search fields require persistent labels or accessible names. Placeholder text alone is not a label.

Images need meaningful alt text when informative and empty alt attributes when decorative.

Carousel controls must be keyboard accessible, labelled and paused during interaction.

The heading order must be one H1, then logical H2 and H3 levels.

12.3 Performance

Preload only the true above-the-fold hero image. Lazy-load all lower images.

Serve responsive images with srcset and sizes. Do not send desktop hero files to small phones.

Avoid adding a new slider library if the current system can provide accessible scrolling.

Target Core Web Vitals: LCP under 2.5s, CLS under 0.1, INP under 200ms on typical mobile connections.

Remove unused homepage CSS and JavaScript introduced by deleted sections.
